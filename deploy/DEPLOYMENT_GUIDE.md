# Полное руководство по развертыванию LumiCRM на Linux Ubuntu и доступу через интернет

В этом документе подробно описаны все способы размещения приложения в интернете, работы с базой данных, создания резервных копий и настройки бесплатного SSL-сертификата.

---

## 1. Архитектура и выбор хостинга

### 1.1. Где размещается приложение и база данных?
* **Приложение**: Серверная часть работает на **Node.js (Express)**, отдавая как API, так и адаптивный веб-интерфейс.
* **База данных**: Хранится в постоянном файле `data/lamps.db` (SQLite в режиме WAL). Все запросы и структура таблиц спроектированы так, чтобы при желании вы могли переключиться на внешний PostgreSQL (Supabase / Neon / Render) без изменения кода бизнес-логики.
* **Перенос на другой сервер**: Чтобы перенести всю систему на другой сервер, достаточно просто скопировать папку проекта и файл `data/lamps.db` (или загрузить бэкап через раздел «Настройки» в веб-интерфейсе).

| Вариант | Стоимость | Сложность | Описание |

| **Cloudflare Tunnel** (домашний ПК или мини-сервер) | **0 руб (Бесплатно)** | Очень просто | Запускаете приложение у себя на ПК/ноутбуке или домашнем Linux, Cloudflare дает постоянный защищенный адрес `https://your-crm.trycloudflare.com` с доступом со смартфона из любой точки мира. |

## 3. Развертывание на Ubuntu 24.04 / 22.04 LTS (Пошагово)

### Шаг 1: Подключение к вашему серверу Ubuntu по SSH
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

### Шаг 2: Клонирование или загрузка проекта
```bash
git clone https://github.com/your-username/lamp-crm.git /var/www/lamp-crm
cd /var/www/lamp-crm
```
*(Или скопируйте файлы через WinSCP / FileZilla в папку `/var/www/lamp-crm`)*.

### Шаг 3: Запуск автоматической установки
```bash
chmod +x deploy/deploy-ubuntu.sh
./deploy/deploy-ubuntu.sh
```
Скрипт автоматически:
1. Установит Node.js 20 LTS, Nginx, SQLite3, брандмауэр UFW.
2. Установит зависимости `npm`.
3. Настроит автозапуск службы `lamp-crm` через `systemd`.
4. Настроит Nginx reverse proxy.

## 4. Развертывание через Docker и Docker Compose

Если вы предпочитаете Docker:
```bash
cd deploy
docker compose up -d --build
```
Приложение запустится в изолированном контейнере, а база данных будет надежно сохраняться в томе `lamp_crm_data`.

## 5. Подключение домена и бесплатного HTTPS (SSL) сертификата

Чтобы приложение открывалось по красивому защищенному адресу (например, `https://lamps.mycompany.com`):

1. В панели вашего регистратора домена добавьте **A-запись** с IP-адресом вашего Ubuntu сервера:
   * Имя: `lamps` (или `@`)
   * Значение: `IP_ВАШЕГО_СЕРВЕРА`
2. На сервере Ubuntu выполните команду получения сертификата Let's Encrypt:
   ```bash
   sudo apt-get install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d lamps.mycompany.com
   ```
   Certbot автоматически настроит HTTPS, перенаправление с HTTP и автопродление сертификата каждые 90 дней.

## 6. Как открыть приложение через интернет со смартфона и ПК (Бесплатный метод Cloudflare Tunnel)

Если вы запускаете сервер локально и хотите получить мгновенный доступ через интернет со смартфона:
1. Скачайте утилиту `cloudflared` (на Windows или Linux).
2. Запустите одну команду:
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
3. Cloudflare выдаст вам ссылку вида `https://random-words.trycloudflare.com`.
4. Откройте эту ссылку на телефоне в браузере Safari / Chrome — и вы получите полноценный доступ к CRM!

## 7. Резервное копирование базы данных

### Ручное скачивание:
1. Откройте раздел меню **«Настройки»**.
2. В блоке «База данных и Резервное копирование» нажмите кнопку **«Скачать резервную копию (.sqlite)»**.
3. Файл сохранится на ваш компьютер или телефон.

### Автоматическое резервное копирование по расписанию (Cron на Ubuntu):
Создайте ежедневный бэкап в 03:00 ночи:
```bash
crontab -e
```
Добавьте строку:
```bash
0 3 * * * cp /var/www/lamp-crm/data/lamps.db /var/backups/lamps_$(date +\%Y\%m\%d).db
```
Копии будут автоматически сохраняться в `/var/backups/`.
