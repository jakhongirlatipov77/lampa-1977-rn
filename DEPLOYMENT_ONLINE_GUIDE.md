# Пошаговая инструкция: Публикация веб-приложения Keramika Sintez (Lamp CRM) в интернете

Данное руководство позволит вам развернуть проект в облаке за 10–15 минут, получить постоянную ссылку с бесплатным HTTPS-сертификатом и подключаться с компьютеров, ноутбуков, смартфонов и планшетов.

---

## 📋 Общая схема архитектуры

```
[Смартфон / Планшет / ПК]
           │ (HTTPS)
           ▼
 [Vercel Cloud Hosting / Edge CDN]
  (Фронтенд SPA + Serverless API)
           │ (SSL TCP/Pooler)
           ▼
[Supabase Cloud Database (PostgreSQL)]
 (Хранение: Клиенты, Прайс, Заказы, Выплаты, Статистика)
```

---

## ШАГ 1. Создание облачной базы данных на Supabase (PostgreSQL)

База данных **Supabase** бесплатна, надежна и хранит все данные в облаке с автобекапами.

1. Перейдите на официальный сайт [https://supabase.com](https://supabase.com) и нажмите **Start your project** (или **Sign In** через GitHub / Google).
2. Нажмите **New Project** (Новый проект):
   * **Name**: `lamp-crm` (или любое название).
   * **Database Password**: Придумайте надежный пароль и **обязательно сохраните его** (он понадобится для подключения).
   * **Region**: Выберите ближайший регион (например, `Central EU (Frankfurt)` или `East US`).
   * **Pricing Plan**: Free plan ($0).
3. Нажмите **Create new project** и подождите 1–2 минуты, пока база инициализируется.
4. Получите строку подключения **DATABASE_URL**:
   * В левом меню нажмите на иконку шестеренки **Project Settings** (Настройки проекта) -> **Database**.
   * Прокрутите до раздела **Connection parameters** / **Connection string**.
   * Выберите вкладку **URI** (или **Nodejs**).
   * Скопируйте строку вида:
     ```
     postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres
     ```
     *(Если используется режим пулера / Connection Pooler, можно выбрать порт `6543` или `5432`).*
   * Замените `[YOUR-PASSWORD]` на реальный пароль от базы, который вы задали на шаге 2.

> [!NOTE]
> Схему таблиц вручную создавать не требуется: при первом запуске приложение **автоматически создаст все 10 таблиц, индексы, учетную запись администратора (`admin` / `admin123`) и начальные демонстрационные данные**!

## ШАГ 2. Создание репозитория на GitHub и загрузка проекта

1. Перейдите на [https://github.com](https://github.com) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите **`+`** -> **New repository** (Новый репозиторий).
3. Заполните параметры:
   * **Repository name**: `lamp-sales-crm` (или `keramika-sintez`).
   * **Visibility**: Рекомендуется выбрать **Private** (Приватный, чтобы ваш код и структура были видны только вам).
   * Галочки "Add a README file" и ".gitignore" ставить **не нужно** (они уже есть в проекте).
4. Нажмите кнопку **Create repository**.
5. Загрузите файлы из папки проекта `f:\Antigravity\Lamp` в созданный репозиторий.

### Команды для терминала / командной строки (выполнить в папке проекта):
```bash
# 1. Перейдите в папку проекта (если еще не в ней)
cd /d f:\Antigravity\Lamp

# 2. Инициализируйте Git (если еще не инициализирован)
git init

# 3. Добавьте все файлы (папка node_modules и .env будут автоматически исключены благодаря .gitignore)
git add .

# 4. Сделайте первый коммит
git commit -m "Initial commit: Ready for Vercel & Supabase deployment"

# 5. Укажите основную ветку main
git branch -M main

# 6. Привяжите ваш GitHub репозиторий (замените URL на ваш из шага 4)
git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/lamp-sales-crm.git

# 7. Отправьте код на GitHub
git push -u origin main
```

## ШАГ 3. Размещение приложения на Vercel

Vercel предоставляет бесплатный быстрый хостинг с мгновенным SSL-сертификатом и автоматическим обновлением сайта при каждом изменении на GitHub.

1. Перейдите на [https://vercel.com](https://vercel.com) и зарегистрируйтесь / войдите через **Continue with GitHub**.
2. В панели управления нажмите **Add New...** -> **Project**.
3. В списке репозиториев найдите ваш репозиторий `lamp-sales-crm` и нажмите **Import**.
4. В блоке **Configure Project**:
   * **Project Name**: можете оставить по умолчанию или указать, например, `keramika-crm`.
   * **Framework Preset**: выберите `Other` (настройки уже прописаны в `vercel.json`).
   * **Root Directory**: `./`.
5. Разверните блок **Environment Variables** (Переменные окружения) и добавьте:

| Имя переменной (Key) | Значение (Value) | Описание |
| :--- | :--- | :--- |
| `DATABASE_URL` | `postgresql://postgres:ПАРОЛЬ@db.XXXX.supabase.co:5432/postgres` | Ваша строка подключения из Supabase |
| `NODE_ENV` | `production` | Режим работы приложения |
| `REQUIRE_DEVICE_MAC` | `false` | Разрешает вход со смартфонов, планшетов и любых ПК |
| `SESSION_SECRET` | `любая_случайная_секретная_фраза_из_30_символов` | Ключ защиты сессий |

6. Нажмите кнопку **Deploy** (Развернуть).
7. Подождите 1–2 минуты. Vercel развернет фронтенд и бэкенд и покажет экран успеха: **"Congratulations! What's next?"**.
8. Нажмите на изображение проекта или ссылку, чтобы открыть ваше готовое веб-приложение!

## ШАГ 4. Получение постоянной ссылки и первый вход

1. Ваше приложение получит постоянную защищенную ссылку вида:
   `https://keramika-crm.vercel.app` (или сгенерированное вами имя).
2. Откройте эту ссылку на любом компьютере, ноутбуке, iPhone или Android-смартфоне.
3. Данные для первого входа:
   * **Логин:** `admin`
   * **Пароль:** `admin123`
4. Сразу после входа рекомендуется перейти в раздел **«Настройки»** -> **«Смена пароля»** и задать свой постоянный пароль.

## ШАГ 5. Настройка собственного домена (в будущем)

Если вы захотите подключить собственный домен (например, `crm.sintez.uz` или `mycompany-crm.com`):

1. В панели управления **Vercel** откройте ваш проект.
2. Перейдите в **Settings** (Настройки) -> **Domains** (Домены).
3. В поле ввода укажите ваш домен или поддомен (например, `crm.vash-sait.com`) и нажмите **Add**.
4. Vercel покажет нужную DNS-запись (обычно **CNAME** `cname.vercel-dns.com` или **A-запись** на IP Vercel `76.76.21.21`).
5. Зайдите в панель управления вашего регистратора доменов (где куплен домен) и добавьте указанную DNS-запись.
6. В течение 5–15 минут Vercel автоматически выпустит бесплатный SSL-сертификат, и система станет доступна по вашему личному домену.

## 🔒 Безопасность данных

* Все пароли пользователей хранятся в зашифрованном виде (хеширование по стандарту `bcrypt` с солью).
* Файлы конфигураций с паролями (`.env`) защищены файлом `.gitignore` и не попадают в открытый доступ на GitHub.
* Соединение с облачной базой Supabase защищено шифрованием SSL/TLS.
* Все операции создания, изменения и удаления заказов, клиентов, товаров и выплат синхронизируются в режиме реального времени в облачной базе PostgreSQL.
