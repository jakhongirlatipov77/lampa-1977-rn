# Keramika Sintez — Веб-приложение для учета продаж ламп и взаиморасчетов с производителями

Полноценная production-ready система для автоматизации торговли лампами, ведения клиентской базы, многопозиционных заказов, точного расчета себестоимости и чистой прибыли, распределения долей между производителями, учета выплат и долгов, а также формирования аналитических отчетов и выгрузки в Excel.

---

## 🌟 Основные возможности системы

1. **Главная панель (Dashboard)**:
   * Выручка, себестоимость, чистая прибыль за текущий месяц с отображением маржинальности.
   * Количество проданных ламп и активных клиентов.
   * Блоки распределения прибыли между двумя производителями (Начислено, Получено, Остаток задолженности).
   * Интерактивные диаграммы помесячной динамики и топ товаров.

2. **Прайс-лист (Каталог ламп)**:
   * Наименование, артикул, цена продажи, себестоимость, прибыль с единицы, маржинальность (%), бренд/производитель, статус (активна / в архиве).
   * Поиск, сортировка и моментальное переключение статуса.

3. **База клиентов**:
   * ФИО, город, телефон, адрес доставки, заметки.
   * Автоматический расчет LTV (всего заказов, сумма покупок за все время, принесенная прибыль).
   * Полная история заказов с детализацией по каждой сделке.

4. **Оформление заказов (Новый заказ)**:
   * Поддержка нескольких ламп в одном заказе.
   * Автоподстановка цен и себестоимости из актуального прайс-листа.
   * Фиксация снимков цен (Price Snapshots) на момент сделки — изменение прайса в будущем не ломает старые заказы.
   * Мгновенный расчет: Сумма = Цена × Кол-во, Себестоимость = Себест. 1 шт × Кол-во, Прибыль = Сумма − Себестоимость.
   * Онлайн предпросмотр распределения прибыли между фабриками.

5. **Журнал продаж (Заказы)**:
   * Фильтры по клиенту, городу, статусу, лампе, датам.
   * Мягкая отмена заказов (статус `cancelled`) с немедленным автопересчетом всех показателей.
   * Детальный просмотр и печать состава заказа.

6. **Расчеты с производителями и Выплаты**:
   * Настройка процентных долей (по умолчанию 50% / 50%, можно задать 60% / 40%, 70% / 30% и т.д.).
   * Пользовательские названия фабрик/производителей.
   * Журнал выплат (наличные, карта, банк) с автоматическим контролем остатка задолженности.

7. **Статистика и Аналитика**:
   * Разрез по клиентам (рейтинг по выручке, прибыли и числу купленных ламп).
   * Разрез по товарам (продажи в штуках, выручка, маржинальность).
   * Помесячная сводная таблица с долями каждого производителя, выплатами и долгами.

8. **Экспорт и Резервное копирование**:
   * Экспорт любых таблиц в Excel (`.xlsx`) и CSV в 1 клик.
   * Ручное скачивание базы данных SQLite (`.sqlite`) и восстановление из файла.

9. **Адаптивность и Дизайн**:
   * Полная поддержка смартфонов (iOS/Android) с мобильной нижней панелью навигации.
   * Темная и светлая темы оформления.
   * Форматирование всех сумм с разделителем тысяч (`1 250 000 сум`).

## 🚀 Быстрый запуск

### Запуск на локальном компьютере:
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск приложения
npm start
```
Откройте в браузере: `http://localhost:3000`
* **Логин**: `admin`
* **Пароль**: `admin123`

### Тестирование расчетов:
```bash
npm test
```
